# RABTO

Responsive web application and installable PWA connecting physical products to digital experiences through NFC and QR.

## Local development
- Node.js 22+
- npm 10+

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Quality checks
```bash
npm run lint
npm run typecheck
npm run build
```

## Current status
Initial Next.js web foundation and Arabic RTL landing page. Database, authentication, resolver, product lifecycle, and customer/admin workspaces will be implemented in stages.
